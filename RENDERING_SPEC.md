# Illustrative Explore rendering
FLEX procedural folds and luminous ribbons use the existing model clock. They do not predict flame geometry or temperature.
BASS-II airflow intensity is a dimensionless visual control, not a measured velocity. Direction and intensity deform the flame mesh while paused or playing without changing illustrative spread timing. The grid floor has been removed. Rod diameter uses the same display scale as the 57.15 mm reported axial length; hemispherical caps remain illustrative end treatment. Neither scene is a combustion solver.
